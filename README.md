## 🎯 这个软件干什么的

**Eklose (翼课校长)** 是一款专为**翼课网（翼课学生）**用户打造的轻量高效答案提取与考试辅助工具 📖

通过翼课账号云端无感接入，Eklose 会直接从官方接口同步学习中心考试列表与常规作业任务，并在设备本地全自动完成标准答案结构化解析，让你在极简舒适的界面中清晰查阅标准答案、听力文本与答题指导。

### 核心功能亮点：
- 📑 **考试与作业双重全覆盖**：
  - **当前学习中心考试任务**：同步最新的进行中考试试卷，后台自动解析。
  - **历史学习中心考试任务**：一键回溯历史考试试卷与答题记录。
  - **当前常规作业**：涵盖日常老师布置的听说读写各小项任务。
  - **历史完成作业**：随时查阅已提交作业的试题与对应参考答案。
- 📊 **全班成绩排名与多模块解析 (v1.2.0+)**：支持考试多模块细分查看、班级成绩榜单解析与排名统计展示。
- 🔑 **灵活便捷的双登录模式**：
  - **实名认证登录**：支持省市、区县学校一键检索，输入学生姓名与密码即可轻松登录（支持同名账号智能筛选）。
  - **账号密码登录**：直接使用翼课已有 username 与密码极速鉴权。
- 📤 **便捷答案导出与分享**：支持一键复制标准答案纯文本，以及自动生成高清答案长图卡片分享。
- 🎨 **前沿现代 Miuix 视觉设计**：深度基于 `miuix` 现代组件库打造，支持 Miuix Blur 实时毛玻璃模糊、深色/AMOLED 纯黑主题、响应式 NavigationRail，纯净无广告。

## 🚀 极速上手使用教程

### 第一步：获取与安装应用

1. 推荐前往 **[LastStudio 官方极速下载通道](https://lastudio.cc/download?app=eklose)** 获取最新 APK（免登录、高可用 CDN 直链）；
2. 亦可在 [GitHub Releases 页面](https://github.com/laststudio/eklose/releases) 或 [网盘分流](https://oplist.lastudio.cc/eklose_release) 下载；
3. 下载完成后安装至 Android 手机（如系统提示未知应用来源，授权允许即可）；
4. 打开 **Eklose (翼课校长)** 应用。

> 📌 **系统环境要求**：当前版本要求 Android 13（API 33）或更高版本，以获得最佳的 Material You 与 Miuix 现代动效体验。

---

### 第二步：选择最适合你的登录方式

| 登录方式 | 推荐等级 | 适用人群与场景 | 特点说明 |
| :--- | :---: | :--- | :--- |
| **🏫 实名登录** | ⭐⭐⭐ **最推荐** | 只记得学生姓名、所在学校和日常密码 | 支持按区县检索全国学校，支持同名账号选择 |
| **🔑 账号密码登录** | ⭐⭐ **直接稳定** | 清楚知晓自己的翼课系统登录名 (username) 与密码 | 步骤最少，直连鉴权 |

---

### 第三步：登录你的翼课账号

#### 模式一：实名登录（推荐）
1. 进入应用底栏 **“主页”**；
2. 点击顶部的 **“登录状态”** 卡片；
3. 登录方式切换至 **“实名登录”**；
4. 输入你的学校名称关键字（可精确到区县），点击搜索；
5. 在匹配列表中选中你的所属学校；
6. 输入学生真实姓名与账号密码，点击 **“实名登录”**；
7. 若学校内存在同名同姓账号，在弹出列表中确认你的账号 UID 即可完成登录。

#### 模式二：账号密码登录
1. 进入应用底栏 **“主页”**，点击 **“登录状态”**；
2. 切换至 **“账号密码登录”** 标签；
3. 输入翼课账号 Username 与密码；
4. 点击 **“账号密码登录”**，成功后主页状态卡片将展示 UID。

---

### 第四步：拉取并解析任务

1. 进入底部导航的 **“读取”** 页面；
2. 根据需求选择任务分类来源：
   - **当前学习中心考试任务**
   - **历史学习中心考试任务**
   - **当前作业**
   - **历史作业**
3. 点击右下角 **“读取”** 浮动按钮；
4. 等待任务列表加载完成，Eklose 将在后台全自动并发解构并计算标准答案。

---

### 第五步：查看、核对与导出答案

- 列表中的试卷卡片在解析完成后变为可点击状态；
- 点击任务卡片即可进入详尽的试题答案页面：
  - 清晰查阅官方标准选项、听力填空文本及录音朗读参考句；
  - 答案页面右上角菜单支持 **“复制答案文本”** 与 **“分享答案高清长图”**；
- 若遇到列表未读出，可排查：
  - 确认账号内老师是否实际发布了对应任务；
  - 检查网络连接是否通畅；
  - 历史任务如记录较多，可在设置中开启全分页读取模式；
  - 保持应用为最新版本。

## ☁️ 云端读取机制与隐私安全

- **云端解析机制**：Eklose 绝不读取手机本地应用私有数据目录，而是通过标准化接口直连拉取任务元数据并在本地安全沙盒内完成解析；
- **权限安全无忧**：
  - 仅需最基础的网络访问权限；
  - **无需存储权限**、**无需 Root 权限**、**无需 Shizuku**；
- **凭证存储安全**：登录生成的 Token 仅保存在本机私有沙盒中；如关闭“保存登录状态”，退出应用即清除临时凭证。
